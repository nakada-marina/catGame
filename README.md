# ぐりおのねこカフェ

店長ねこ「ぐりお」といっしょに、小さなねこカフェを人気のお店に育てるドット絵の経営シミュレーションゲームです。
`index.html` ひとつで動きます（ブラウザで開くだけ）。

## あそびかた

- **ふきだしをタップ**：注文をうける。注文は画面下のキッチンに伝票として届きます。待たせすぎると怒って帰ってしまいます。しばらくだれも注文をききに行かないと、手の空いたねこがメモを持って注文をとりに行きます（材料があるときだけ。「配膳がはやい」ねこは注文とりもはやい）
- **キッチン**：設備をタップすると調理スタート
  - コーヒーマシン（コーヒー・ミルクティー・パフェ）：カップのみどりの線までたまったらタップ
  - フライパン（パンケーキ・オムライス）：きつね色でキラキラしたらタップ
  - オーブン（クッキー・ケーキ）：ベルが光ったらタップ
  - ちょうどいいときにタップすると「パーフェクト！」で満足度とチップがアップ。早すぎると失敗
  - できた料理は「できあがり」台にならび、ねこたちが自動で席まで運ぶ。急ぐときは台の料理をタップですぐ届く。放っておくと冷める
  - ショップの「キッチン」で2台目の設備を買える
- **テーブルのお皿**：ねこたちがお皿を取りに行って、カウンターまで運んで片付けてくれる。急ぐときはタップですぐ片付け。片付くまで次のお客さんは座れません
- **ねこをタップ**：なでる（ごきげんUP）
- **床のねこの毛をタップ**：おそうじ。毛が多いとお客さんの満足度が下がります
- **ごはん**：ねこのごはんを補充。おなかがすいたねこは元気がなくなります
- **仕入れ**：料理の材料を買う。材料がないと料理を出せません（ふきだしに✕）
  - 営業中の仕入れは「おいそぎ便」で1.5倍。閉店後にあしたの分をまとめて買うとおトク
  - 材料の値段は毎日かわります（やすい／たかい）
  - 牛乳・たまご・いちご・生クリームは日もちが短く、使いきれないと捨てることに
  - 冷蔵庫とたなに入る量には上限あり。ショップで大きくできます
  - カウンターの上の「材料だな」で在庫が目で見える。空っぽは赤、あすで期限切れは黄色の「!」。たなをタップで仕入れ画面
- **ショップ**：カウンター席（3席まで）、テーブル、キャットタワー、クッション、観葉植物などの家具や新メニュー、新しいねこ、アルバイトさん
- **ニャイミー**：スキマ時間にはたらきたい野良ねこを、数時間だけ雇えるアプリ。日替わりで3匹が応募。配膳がはやい・片付けじょうず・招きねこ（お客さんがふえる）・いやし系（満足度アップ）の得意わざあり。報酬は来てもらうときに払う
- **ニャックス**：店長ぐりおが毎日の閉店後に、その日のお店のことを勝手につぶやくSNS（お客さんの数、パーフェクトな料理、新しいなかま、ぽんたの昼寝回数、ほめられたメニューなど＋閉店後のお店の写真）。ポストは結果画面でも見られる。いいねはつぎの日の営業中に伸び、一定をこえるとバズってお客さんがどっと来る。フォロワーが多いほど、ふだんのお客さんも少しふえる。満足したお客さんや怒ったお客さんのポストもタイムラインに流れる
- **はやさ**：×1 / ×2 / ×3

1日は 10:00〜19:00。閉店すると売上とお客さんの声が見られます。
ねこがお客さんのそばに行くと満足度が上がり、チップがもらえることも。

店長のぐりおが登場。ひょうばん★2になると、弟の **ぽんた** を従業員としてやとえます。ぽんたはできた料理を席まで運んでくれますが、よく寝たり毛づくろいでサボったりします（タップで起こせます）。

店長のぐりおが、はじめての説明や「SNSで話題に！」「常連さんが来た！」などのイベントで話しかけてきます。

目標は **ひょうばん ★5** と **もちきん ¥100,000**。進行はブラウザに自動保存されます。

## スマホで遊ぶ（GitHub Pages）

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
3. 数分後に表示されるURLを開くと遊べます

## キャラクター素材と表示検証

`character-detail.js` はユーザーの「ぐりおとぽんたのねこカフェ素材集.png」（1536×1024）から抽出した透過PNGを格納します。全身約90〜120pxの元の詳細を保ち、従来の32〜58px画像の拡大による代用をやめました。短毛キジ白のぐりお、茶色の長毛キジトラのぽんたを維持します。128×144の共通フレーム内で足元を統一しています。

歩行4コマは設定画の歩行ポーズを基準に、足先の水平位置のみ±2px変えています。顔・頭・胴体は完全に同じ画素です。待機・走る・接客・配膳・お辞儀・ジャンプ・座る・掃除・驚く・喜ぶは設定画のポーズを使用します。睡眠・8種類の表情は従来のアトラスを保持しているため解像度改善の対象外です。毛づくろい・調理は専用の連続コマがなく既存ポーズで代用しています。通常のぐりおの会話用顔は、同じキャラクターの正常な口元から補修済みです。

店内は最大640pxの横幅を維持し、高さを従来の半分（縦横比300:448）にしました。家具・猫・客は基準位置だけを上下に移動させ、全身を縦につぶしません。壁・床の装飾は高さに合わせて描画します。操作ドックと会話位置を維持します。ゲームの座標・セーブキー `grio-cafe-v1`・セーブ形式は変更していません。

`touch-controls.js` は連続タップの標準ズームを抑止し、ボタンは1タップ1クリックで処理します。縦ドラッグと複数指ジェスチャーは維持します。CanvasはDPRに応じた整数内部倍率、画像補間なしで描画します。

Playwrightで `node tests/browser-check.cjs` を実行できます。必要に応じて `CHROMIUM_PATH` を指定してください。5種類の画面サイズ、半分の店内高、連続タップ、猫のタップとスクロール、歩行全コマの顔の画素一致、全素材の表示、注文・調理・配膳・メニュー・セーブ再開を検証します。iPhone実機Safariは未検証です。
