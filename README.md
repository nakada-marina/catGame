# ぐりおの冒険

ねこの「ぐりお」が、さかなを集めながらおうちを目指すドット絵のレトロアクションゲームです。
`index.html` ひとつで動きます（ブラウザで開くだけ）。

## あそびかた

| そうさ | キーボード | スマホ |
| --- | --- | --- |
| いどう | ← → / A D | ◀ ▶ ボタン |
| ジャンプ | スペース / Z / ↑ | ジャンプボタン（長押しで高く） |
| スタート | Enter | ジャンプボタン / 画面タップ |
| 一時停止 | P | 一時停止ボタン |
| 音のON/OFF | M | 音ボタン |

- ねずみは上からふむと倒せます。ハリネズミはふめないので、よけましょう。
- 「？」ブロックを下からたたくと、さかなが出ます。さかな30匹で1UP。
- ステージは 1-1「ひだまりの はらっぱ」と 1-2「よるの まちはずれ」の2つ。
- ゴールのポールにタッチして、ぐりおをおうちに帰してあげよう。

## スマホで遊ぶ（GitHub Pages）

1. リポジトリの Settings → Pages を開く
2. Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
3. 数分後に表示されるURLを開くと遊べます
