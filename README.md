# ぐりおのねこカフェ

店長ねこ「ぐりお」といっしょに、小さなねこカフェを人気のお店に育てるドット絵の経営シミュレーションゲームです。
`index.html` ひとつで動きます（ブラウザで開くだけ）。

## あそびかた

- **ふきだしをタップ**：注文をうける。注文は画面下のキッチンに伝票として届きます。待たせすぎると怒って帰ってしまいます。しばらくだれも注文をききに行かないと、手の空いたねこがメモを持って注文をとりに行きます（材料があるときだけ。「配膳がはやい」ねこは注文とりもはやい）
- **キッチン**：設備をタップすると調理スタート
  - コーヒーマシン（コーヒー・ミルクティー・パフェ）：カップのみどりの線までたまったらタップ
  - フライパン（パンケーキ・オムライス）：きつね色でキラキラしたらタップ
  - オーブン（クッキー・ケーキ）：ベルが光ったらタップ
  - ちょうどいいときにタップすると「パーフェクト！」で満足度とチップがアップ。早すぎると失敗
  - できた料理は「できあがり」台にならび、ねこたちが自動で席まで運ぶ。急ぐときは台の料理をタップですぐ届く。放っておくと冷める
  - ショップの「キッチン」で2台目の設備を買える
- **テーブルのお皿**：ねこたちがお皿を取りに行って、カウンターまで運んで片付けてくれる。急ぐときはタップですぐ片付け。片付くまで次のお客さんは座れません
- **ねこをタップ**：なでる（ごきげんUP）
- **床のねこの毛をタップ**：おそうじ。毛が多いとお客さんの満足度が下がります
- **ごはん**：ねこのごはんを補充。おなかがすいたねこは元気がなくなります
- **仕入れ**：料理の材料を買う。材料がないと料理を出せません（ふきだしに✕）
  - 営業中の仕入れは「おいそぎ便」で1.5倍。閉店後にあしたの分をまとめて買うとおトク
  - 材料の値段は毎日かわります（やすい／たかい）
  - 牛乳・たまご・いちご・生クリームは日もちが短く、使いきれないと捨てることに
  - 冷蔵庫とたなに入る量には上限あり。ショップで大きくできます
  - カウンターの上の「材料だな」で在庫が目で見える。空っぽは赤、あすで期限切れは黄色の「!」。たなをタップで仕入れ画面
- **ショップ**：カウンター席（3席まで）、テーブル、キャットタワー、クッション、観葉植物などの家具や新メニュー、新しいねこ、アルバイトさん
- **ニャイミー**：スキマ時間にはたらきたい野良ねこを、数時間だけ雇えるアプリ。日替わりで3匹が応募。配膳がはやい・片付けじょうず・招きねこ（お客さんがふえる）・いやし系（満足度アップ）の得意わざあり。報酬は来てもらうときに払う
- **ニャックス**：店長ぐりおが毎日の閉店後に、その日のお店のことを勝手につぶやくSNS（お客さんの数、パーフェクトな料理、新しいなかま、ぽんたの昼寝回数、ほめられたメニューなど＋閉店後のお店の写真）。ポストは結果画面でも見られる。いいねはつぎの日の営業中に伸び、一定をこえるとバズってお客さんがどっと来る。フォロワーが多いほど、ふだんのお客さんも少しふえる。満足したお客さんや怒ったお客さんのポストもタイムラインに流れる
- **はやさ**：×1 / ×2 / ×3

1日は 10:00〜19:00。閉店すると売上とお客さんの声が見られます。
ねこがお客さんのそばに行くと満足度が上がり、チップがもらえることも。

店長のぐりおが登場。ひょうばん★2になると、弟の **ぽんた** を従業員としてやとえます。ぽんたはできた料理を席まで運んでくれますが、よく寝たり毛づくろいでサボったりします（タップで起こせます）。

店長のぐりおが、はじめての説明や「SNSで話題に！」「常連さんが来た！」などのイベントで話しかけてきます。

## キャラクター素材と表示検証

ぐりおとぽんたの全身素材は `cat-motions-grio.png` と `cat-motions-ponta.png`（各1024×1536、各24コマ）に揃えています。前・後ろ・右向きの歩行を各4コマ、待機、配膳、コーヒー／ケーキ、掃除、座る、睡眠、箱での睡眠、驚く、喜ぶ、お辞儀、ジャンプ、毛づくろいを同じキャラクター見本から描き直しました。ぐりおは短毛のキジ白、ぽんたは長毛の茶色キジトラ。ぽんたに白い毛はなく、口元・あご・胸・手足まで茶色で揃えています。黒いエプロン、金色の縁、オレンジの猫模様を共通にしています。

`cat-motions.js` はキャラクターごとに全ポーズ共通の倍率を求め、128×144のフレームに足元を揃えて配置します。座る・眠る姿を立ち姿と同じ高さへ引き伸ばしません。左右の移動には右向き歩行の左右反転を使います。走る確認用の姿は横歩行の足上げコマを共用します。会話の顔8種類は `chars.webp` の素材を保持し、ぐりおの通常顔の口元補修も保持します。`character-detail.js` は元の見本として残していますがゲームでは読み込みません。

店内は最大640pxの横幅を維持し、高さを従来の半分（縦横比300:448）にしました。家具・猫・客は基準位置だけを上下に移動させ、全身を縦につぶしません。壁・床は短い画面の座標で描き、装飾は縦横同じ倍率で配置します。操作ドックと会話位置を維持します。ゲームの座標・セーブキー `grio-cafe-v1`・セーブ形式は変更していません。

`touch-controls.js` は連続タップの標準ズームを抑止し、ボタンは1タップ1クリックで処理します。縦ドラッグと複数指ジェスチャーは維持します。CanvasはDPRに応じた整数内部倍率、画像補間なしで描画します。

Playwrightで `node tests/browser-check.cjs` を実行できます。必要に応じて `CHROMIUM_PATH` を指定してください。5種類の画面サイズ、半分の店内高、連続タップ、猫のタップとスクロール、全ポーズの共通倍率と足元、専用の毛づくろい、歩行全コマと全素材の表示、注文・調理・配膳・メニュー・セーブ再開を検証します。iPhone実機Safariは未検証です。

向き：設定画の歩行ポーズは右向きです。`face=+1` は原画、`face=-1` は左右反転を使います。お辞儀は通常の立ち姿を維持し、注文受付の最後18フレームで足元を基準に最大6度だけ前傾して戻ります。sin²による緩やかな開始・終了で、顔の差し替えや画像の縦圧縮はありません。深く丸まった設定画のポーズはゲーム中のお辞儀には使いません。伸びに深いお辞儀を割り当てる処理を廃止しました。左右それぞれの移動と、お辞儀前後の待機への復帰をテストします。

自動注文受付：注文表示から30フレーム経過後、待機・散歩・客との交流より注文受付を優先して担当猫を派遣します。ぐりおは睡眠中も仕事へ戻ります。人のアルバイトは猫が担当済みの注文を横取りしません。手動注文受付を使わず、各状態から移動→注文受付→調理キュー作成→担当解除までテストします。

## 猫の表示サイズとモーション

ぐりおの全身は0.55倍（70×79の表示フレーム）、ぽんたは0.52倍（67×75）で表示します。全身素材は全ポーズ128×144です。`CatArtwork.displaySize` に倍率を集約し、待機・歩行・仕事・休憩で表示倍率を変えません。他の猫と一時スタッフは引き続き0.78倍です。

`CatArtwork.load()` は統一した全身モーションと会話の顔をまとめて返します。`RearWalk.cat()` もぐりお・ぽんたには同じ `CatMotions` の前後歩行を返すので、向きや状態が変わっても古い全身絵へ戻りません。掃除中は掃除、毛づくろい中は専用の毛づくろい絵を選びます。注文受付のお辞儀は立ち絵の最大6度の緩やかな傾きで維持します。

斜めを含む画面奥への移動は後ろ姿、手前へは前向き、真横は左右向きです。他4種類の猫は `cat-facing-extra.png`、人の後ろ姿は `rear-walk-atlas.png` を使います。保存形式は維持しています。

`animation-preview.html` はぐりお・ぽんたの全モーションと会話の顔を56枚のカードで、ゲームと同じ大きさで表示します。`cat-facing-preview.html` は猫6種類の前後歩行を表示します。

`node tests/rear-walk-check.cjs` は48コマの全身素材、全アクションの倍率・切り出し・足元、睡眠の自然な高さ、毛づくろいと掃除の選択、前後横の方向、読み込み順と待機を依存パッケージなしで検証します。`node tests/browser-check.cjs` はPlaywrightによる画面・モーション・注文から配膳・保存再開の検証用です。
